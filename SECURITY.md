# Security Policy

## Supported Versions

Only the latest release and the current `master` branch receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `telexec` seriously. If you discover a security vulnerability, please do not disclose it publicly via an issue or pull request.

Please report vulnerabilities through one of the following channels:
1. **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button under the **Security** tab of the repository on GitHub.
2. **Security Contact**: Contact the project maintainers directly.

Please include as much detail as possible in your report:
- A description of the vulnerability and its potential security impact.
- Clear step-by-step reproduction instructions, sample code, or proof of concept.
- Affected versions and environments.
- Any known mitigations or suggested fixes.

We will acknowledge receipt of your report within 48 hours and coordinate a patch release and advisory before public disclosure.
